# Fuentes UML reconstruidas

Los cinco .puml se editan como texto y se abren con PlantUML (por ejemplo, una extensión de VS Code). No son los archivos originales de draw.io/StarUML: estos no estaban en el repositorio.

Contienen clases y mensajes editables, no imágenes incrustadas. Se reconstruyen a partir de los JPG revisados; no se garantiza equivalencia exacta de todas las líneas, multiplicidades ni disposición visual. Las relaciones inferidas deben revisarse con el grupo. Las imágenes originales incluidas en este ZIP son la referencia visual autoritativa del trabajo existente.

La fuente final conserva diferencias de nombres/firmas y la inicial conserva placeholders. Las secuencias hacen explícitas alternativas para permitir su edición, pero anotan las incompatibilidades pendientes. Estas fuentes requieren revisión antes de sustituir los JPG del repositorio.

Archivos: 01 casos de uso; 02 clases inicial; 03 clases final; 04 secuencia de visitas; 05 secuencia de reportes.
